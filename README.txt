تمرينتي - تثبيت على الموبايل
==============================
التطبيق بيشتغل كتطبيق ويب (PWA) ولازم يترفع على رابط https مرة واحدة:

1) ارفع محتوى المجلد ده (مش الـ zip نفسه) على أي استضافة مجانية:
   - Netlify Drop: افتح app.netlify.com/drop واسحب المجلد
   - أو GitHub Pages / Cloudflare Pages
2) افتح الرابط من موبايلك:
   - أندرويد (Chrome): القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»
   - آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية»
3) هيظهر بأيقونته واسمه، وبيشتغل بعد كده من غير نت.

الملفات: index.html (التطبيق) · manifest.webmanifest · sw.js (العمل بدون نت) · الأيقونات
بياناتك (سجل التمارين) بتتخزن على نفس الموبايل.
